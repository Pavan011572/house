# 3D House Model

An interactive 3D architectural model viewer built with HTML5, CSS3, and JavaScript/WebGL.

## Features
- Interactive 3D camera controls (orbit, pan, zoom)
- Modern architectural blueprint plaque and control dock
- Light and dark theme support
- Responsive viewport fitting for mobile and desktop

## Getting Started
Open `3D House Model.html` (or `index.html`) in any modern web browser.
